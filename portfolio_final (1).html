    📘 How to connect Firebase (step-by-step)
    1. Go to console.firebase.google.com
    2. Create a new project (or open existing)
    3. Click Build → Firestore Database → Create database → choose Test mode
    4. Go to Project Settings ⚙️ → Your apps → Add app → Web (</>)
    5. Copy the firebaseConfig values and paste below
    6. Click 🔌 Connect — you'll see ✅ Connected if it works
    7. Click ⬆️ Push All Data to upload your portfolio to the cloud
    ✅ After that, every edit auto-syncs instantly if Auto-sync is ON
